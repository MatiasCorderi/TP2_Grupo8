HELMUT DITSCH

Pintor plástico argentino exponente del Realismo Vivencial y creador de lienzos monumentales inspirados en los extremos de la naturaleza.

Ver Galería de Obras

En este sitio web se investigó la obra, trayectoria y el universo visual del artista argentino Helmut Ditsch, a través de una propuesta desarrollada con HTML, CSS y JavaScript. El proyecto reúne nueve páginas independientes organizadas en secciones temáticas para recorrer su contexto artístico, e incorpora una galería interactiva con seis obras, un formulario de contacto hecho mediante JavaScript y más funciones interactivas. ¡Te invitamos a investigar este sitio para descubrirlas!
